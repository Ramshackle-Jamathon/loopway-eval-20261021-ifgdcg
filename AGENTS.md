# Evaluation workspace

Work only on this disposable repository and its linked issue and pull request. Do not access other repositories or alter account settings, credentials, webhooks, or Loopway configuration.

Use a feature branch and a git worktree. Never commit directly to main. Do not merge pull requests, force-push, delete branches or repositories, or spawn other agents.

This is a small dependency-free Node project. Run `npm test` and add behavior tests appropriate to the requested change. Keep implementation and documentation focused on the issue and review feedback.

When an issue has a pull request, subsequent feedback belongs in that same branch and pull request. Link the pull request to the Loopway thread using its MCP tool. Keep the thread open while awaiting review.
